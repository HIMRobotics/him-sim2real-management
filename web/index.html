SSH port & first-time access

An unlocked SSH key/agent and a trusted host are required. Password-only login is not automated. If needed, first run this in your normal terminal and verify the host with the robot operator:

ssh YOUR_USER@YOUR_G1_COMPUTER

The app does not store passwords, install SSH keys or bypass host verification.
